# CodeTogether 🚀

**Code. Collaborate. Create. Together.**

CodeTogether is a web-based collaborative coding platform designed to bring developers together in a unified development environment.

It aims to simplify collaborative software development by combining project management, file management, an integrated code editor, real-time communication, and isolated code execution in one application.

### ✨ Key Features

- 🔐 User Authentication – Secure account registration and login.
- 📁 Project Management – Create and manage coding projects.
- 👥 Team Collaboration – Invite team members and manage project access.
- 📝 Integrated Code Editor – Monaco-powered coding environment.
- 💬 Real-Time Communication – Socket.IO-based communication.
- 🗄️ Database Integration – Persistent storage using MySQL and Prisma ORM.
- 🐳 Secure Code Execution – Docker-based isolated execution environment.

### 🛠️ Technology Stack

**Frontend:** React.js, JavaScript, Vite, Monaco Editor

**Backend:** Node.js, Express.js, Socket.IO

**Database:** MySQL 8.0, Prisma ORM

**Code Execution:** Docker

### 🎯 Project Goal

To create a centralized development environment where developers can manage projects, write code, collaborate with teammates, and execute programs more efficiently.

**CodeTogether – One Workspace. Multiple Developers. Shared Creativity.**
